## 三、⛔ 三个必须先确认的缺口

### 缺口 0（2026-10-23 补充）：MG513P10 是电机，驱动板仍未确认

用户答复「MG513P10」——这是**电机型号**，不是驱动板型号。实测规格：

| 项           | 值                      |
| ----------- | ---------------------- |
| 类型          | 12V 直流减速电机             |
| 减速比         | **10:1**               |
| 编码器         | **13 PPR AB 相霍尔编码器**   |
| **编码器输出电平** | **5V** ⚠️              |
| 常见配套驱动      | TB6612 / TB213A（峰值 3A） |

**由此产生三个影响：**

**① 编码器暂时不能接，也不该接**

固件里没有任何编码器代码（`app_config.h` 只有 4 个方向脚 + 2 路 PWM + STBY，  
无 TIM 编码器模式配置）。所以：

- 电机只用 **2 根线**（M+ / M-）接驱动板输出
- 编码器的 4~5 根线**悬空不接**
- 接了也没用，反而增加短路风险

**② 编码器是 5V 输出，绝不能直连 F407**

这是必须记住的：MG513 系列编码器输出 **5V 电平**，而 STM32F407 的 GPIO  
是 **3.3V 耐受**（除少数 FT 引脚外）。直连会损坏引脚。

如果将来要接编码器（做闭环测速），**必须分压**：

```
编码器 A/B 相 ──[33kΩ]──┬── F407 GPIO（3.3V）
                        │
                   [20kΩ]
                        │
                       GND
分压后：5V × 20/(33+20) = 1.89V   ✓ 安全
```

（也有资料用 33k+20k，具体阻值只要分压比 ≤ 0.66 即可）

**③ 减速比 10:1 偏快，靠 PWM 限速**

10:1 的 MG513 空载转速较高（12V 时约 1000 RPM 量级）。  
固件默认 `CTRL_BASE_SPEED_DEFAULT = 350`（千分比 35%），就是为限速准备的。  
第一次试车务必车轮架空，从低占空比开始。

**④ 驱动板仍需确认**

固件按 **带 STBY 的驱动**写（PB11 = STBY），L298N 没有这个脚。  
看到 MG513P10 常见配套是 TB6612，但**必须看驱动板丝印确认**。

### 缺口 1：电机驱动是 L298N（已确认）—— 接法能对上，但固件有个安全漏洞已修

**用户已确认实物为 L298N。** 引脚对应关系完全能对上：

| F407 引脚           | L298N 引脚 | 说明                |
| ----------------- | -------- | ----------------- |
| **PB6**（TIM4_CH1） | **ENA**  | 左电机调速 PWM（20 kHz） |
| **PB12**          | **IN1**  | 左电机方向 1           |
| **PB13**          | **IN2**  | 左电机方向 2           |
| **PB7**（TIM4_CH2） | **ENB**  | 右电机调速 PWM（20 kHz） |
| **PB14**          | **IN3**  | 右电机方向 1           |
| **PB15**          | **IN4**  | 右电机方向 2           |
| **PB11**（STBY）    | **无对应**  | **悬空不接**          |
| GND               | GND      | 必须共地              |

**L298N 供电**：

```
电池 12V ──[保险丝]──[急停]──→ L298N +12V
GND ────────────────────────→ L298N GND
L298N +5V ──→ 若板上 5V-EN 跳线帽在位，可输出 5V 给逻辑；
              若外部已给 5V，**必须拔掉 5V-EN 跳线帽**，否则双源冲突
```

#### ⚠️ 发现并修复的安全漏洞

`motor.c` 原实现：

```c
void motor_enable(bool en)
{
    if (en) {            /* ← 只有使能时才清零 */
        ...PWM 归零、方向脚清零...
    }
    HAL_GPIO_WritePin(STBY, en ? SET : RESET);   /* ← 禁用时只拉 STBY */
    s_enabled = en;
}
```

**对 TB6612 有效**（STBY 拉低 = 硬件切断 H 桥）。  
**对 L298N 无效**（没有 STBY，PB11 悬空，拉低没有任何效果）。

后果：safety 模块判定故障 → 调 `motor_enable(false)` → **电机仍按上一次的  
PWM 与方向继续转**，直到 IWDG 复位或人工断电。

**已修复**（2026-10-23）：改为无论使能与否都先清零 PWM 与方向脚，  
`motor_set()` 在未使能分支也强制清零。

**修复版固件**：`D:\F407\backup\fw407_fixed_20261023.bin`（20,740 字节）

> ⚠️ 注意：该版本用 GCC 14.3.1 重新编译，与原版（20,756 字节）不是逐字节关系。  
> 差异包含：① `_init` 补丁（原 Makefile 用 `-nostartfiles` 导致链接失败，必需）  
> ② motor.c 安全修复 ③ 编译器版本优化差异。  
> 建议先用原始固件验证接线，确认无误后再烧修复版。

### 缺口 2：激光控制完全没有代码

我搜了整个工程：

```bash
grep -rniE "laser" E:/PlantDiseaseProject/_f407build/fw   →  0 条结果
grep -rniE "laser|激光" /j/*.py                            →  0 条结果
```

**F407 固件里没有激光控制，OpenMV 脚本里也没有。**

协议 `@T,SEQ,CLASS,CONF,CX,CY,W,H,DIST` 里只有目标信息，**没有任何"开火"指令**。

这意味着：

- 现在接线时，激光模块**没有信号脚可接**
- 即使接上电源，也不会被任何代码控制
- 要么一直亮（危险），要么一直灭

**必须补一段代码**。最小实现建议（F407 侧，`safety.c` 或新增 `laser.c`）：

```c
/* 在 SYS_AUTO 且 CLASS==WEED 且 CONF>=SAFETY_CONF_MIN 时开激光 */
/* 单次上限 800ms，超时强制关断，且受 STBY 使能状态约束 */
```

这属于阶段 2/3 的工作，**但接线时要预留位置**：先确定激光接哪个 GPIO，  
（建议 PB0 或 PB1，未占用），后面补代码时直接用。

### 缺口 3：固件用 HSI，不用外部晶振

`main.c` 第 16 行注释：

> 板上无外部晶振（沿用 Good_Dog 固件的结论），HSI 16MHz  
> PLLM=16 PLLN=336 PLLP=2 → SYSCLK 168MHz

**如果实际板子上有 8MHz 晶振**，固件也能跑（用内部 HSI），但：

- 时钟精度差（HSI 温漂 ±1%，晶振 ±20ppm）
- **串口波特率会有累积误差**，长时间通信可能偶发误码

**验证方法**：跑起来后看 CRC 错误计数（`proto_stats_t.err_crc`）。  
如果稳定为 0，说明 HSI 够用；如果偶发 CRC 错，考虑改回 HSE。

## 四、接线顺序建议（降低烧板风险）

### 第 1 步：只接调试线，验证芯片活着

```
ST-Link SWDIO → PA13
ST-Link SWCLK → PA14
ST-Link GND   → GND
ST-Link 3.3V  → 3.3V（可选，板子可自供电则不用）
```

用 `STM32_Programmer_CLI.exe -c port=SWD` 确认能读到 `Device ID 0x413`。  
**这一步已经验证通过。**

### 第 2 步：只接视觉链路，验证串口

```
OpenMV P4  → F407 PA10
OpenMV P5  → F407 PA9
OpenMV GND → F407 GND      ★ 必须，不接必乱码
```

**不接电机、不接舵机、不接激光。**  
上电后看 F407 的 `frames_ok` 是否增长。

### 第 3 步：接舵机（单独验证）

```
F407 PA6 → 舵机 A 信号
F407 PA7 → 舵机 B 信号
舵机 VCC → 独立 5V（不要与主控共用一条细线）
舵机 GND → 公共地
```

上电应看到舵机从当前位置**缓慢**转到中位（固件有 10µs/10ms 的缓动）。

### 第 4 步：接电机驱动（车轮必须架空）

按第三节「缺口 1」的 TB6612 接法。**先不接电机，只接信号线**，  
用万用表测 PWMA/PWMB 是否有 PWM 输出、STBY 是否被拉高。

### 第 5 步：接急停（最后接，但必须接）

```
急停按钮一端 → PE0
急停按钮另一端 → GND
```

常开型，按下时 PE0 被拉低，EXTI0 下降沿触发 `safety_estop_isr()`。

### 第 6 步：激光（等代码补完再接）

**现在不要接。** 等补上控制代码、确认默认关断后再接。

## 五、供电接线

```
12V 电池 ──┬──[保险丝]──[急停常闭]──→ TB6612 VM（电机功率）
           │
           └──→ DC-DC 12V→5V ──┬──→ F407 5V
                                ├──→ OpenMV VIN
                                ├──→ TB6612 VCC（逻辑）
                                ├──→ 舵机 VCC（建议独立一路 + 470µF）
                                └──→ 激光模块（经 MOS 开关，暂不接）

所有 GND → 汇流到电池负极同一点（单点接地）
```

**关键点**：

- 舵机启动电流大（SG90 堵转 ~700mA），**入口必须并 470µF**
- 主控 5V 入口并 100µF + 0.1µF
- 电机功率地与信号地**在电池负极单点汇合**，不要串在信号线上

## 七、一句话总结

> 串口、舵机、急停、状态灯这四类接线**可以直接照表接**，固件完全支持。  
> **电机驱动要先确认是不是 TB6612**（固件按带 STBY 的写法），  
> **激光暂时不能接**（两侧都没有控制代码）。

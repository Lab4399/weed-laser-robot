# 植物病虫害识别 + 激光瞄准打击系统 —— 总体方案

> 目标：摄像头识别植物病虫害，自动驱动两轴激光云台，把激光打到病斑/虫害位置。
> 状态：结合本机现有资产（PlantDisease、GOOD DOG、OpenMV、WSL GPU）设计，含分阶段实施与可行性。

---

## 一、系统原理（闭环链路）

```
 ┌────────┐     ┌──────────────┐     ┌──────────────┐     ┌─────────┐
 │ 摄像头  │────▶│ 识别(病虫害) │────▶│ 视觉伺服瞄准  │────▶│ 激光执行 │
 │USB/OpenMV│ 帧 │ YOLOv8/病斑   │ 框  │ 像素误差→角度 │ 舵机 │ 云台+激光 │
 └────────┘     └──────────────┘     └──────────────┘     └─────────┘
                      ▲                     │
                      └──── 下一帧闭环 ◀─────┘
```

1. **识别**：每帧输入 YOLOv8（或颜色病斑分割兜底），输出病害目标框 `(x1,y1,x2,y2,类别,置信度)`。
2. **瞄准**：取目标框中心 `(cx,cy)`，与图像中心 `(W/2,H/2)` 求像素误差，比例控制（P）把误差转成云台角度增量。
3. **打击**：误差进入死区（已瞄准）→ 开激光；误差超出 → 关激光继续追。
4. **安全**：健康叶片不打；两次射击有冷却；可急停。

## 二、硬件选型（最小可运行清单）

| 部件 | 建议 | 说明 |
|---|---|---|
| 摄像头 | USB 摄像头 或 已有 **OpenMV** | OpenMV 已写好在用（320×240 JPEG 串口上传） |
| 识别主机 | 本机 **WSL2 + RTX 5060**（已实测 CUDA 可用） | 跑 YOLOv8 训练/推理 |
| 瞄准云台 | 2× **MG90S 舵机**（水平+俯仰）+ 3D打印/支架 | 俯仰/水平各一轴 |
| 激光模块 | **5mW 红光激光二极管**（≤Class 3R）+ MOS/三极管驱动 | 低功率，务必见"安全"节 |
| 执行器主控 | **Arduino Uno/Nano**（舵机库现成，最简）或 STM32 | 接收串口 ASCII，控舵机+激光 |
| 电源 | 5V（舵机独立供电，勿与 MCU 共用） | 2 舵机 ~1A |

> 注：GOOD DOG（STM32F407）的 4 个直流电机用于**移动**，不适合高精度瞄准；瞄准用**舵机云台**，二者可组合（GOOD DOG 走近 → 云台精瞄）。

## 三、软件模块（本目录已实现）

```
laser_strike/
├─ config.py        全局配置（串口/PID/类别/激光安全参数）
├─ detector.py      识别：YoloDetector(专用+兜底) / BlobDetector(颜色病斑，无模型兜底)
├─ aiming.py        瞄准：视觉伺服，像素误差→云台角度（比例控制+死区+限幅）
├─ actuator.py      执行器：SerialActuator(串口ASCII) / SimActuator(仿真打印)
├─ main.py          主闭环：抓帧→识别→瞄准→开激光；支持图片/摄像头/sim
├─ arduino/
│  └─ laser_gimbal.ino   Arduino 固件：2 舵机云台 + 激光 + 急停
├─ README.md        使用说明
└─ 系统方案.md       本文档
```

### 执行器串口协议（ASCII，每行 `\n` 结尾）
```
P<0-180>   水平舵机角度
T<0-180>   俯仰舵机角度
L1 / L0    激光 开/关
S          急停（回中心+关激光）
```

## 四、分阶段实施与可行性

### 阶段 0（现在即可，0 硬件）—— 软件闭环仿真
- `python main.py --sim`：USB 摄像头 + 打印瞄准/激光动作，画面显示瞄准十字与状态。
- 可行性：**✅ 高**。不依赖模型与硬件，代码已给。

### 阶段 1（无模型也能演示识别）—— 颜色病斑分割
- `python main.py --detector blob --sim`：用 HSV 检测叶片上的褐/黄/白病斑，跑通"识别→瞄准→激光"。
- 可行性：**✅ 高**，适合先验证链路；但只能定位"有色病斑"，不能区分具体病害类别。

### 阶段 2（训练专用病害模型）—— 关键路径
- 现状：`E:\PlantDiseaseProject` 骨架完整，但 **数据集为空（0 图）、无模型、无 data.yaml、无 train.py**。
- 需做：① 下载 PlantVillage 数据集（54k 图/38 类，Kaggle，网络受限需代理/离线）② 补 `train.py`+`data.yaml` ③ 在 **WSL2 GPU** 训练 YOLOv8（RTX 5060，实测 cu130 可用，batch≈8）。
- 可行性：**⚠️ 中**。GPU 已就绪；瓶颈是数据集下载（当前外网受限）。

### 阶段 3（接硬件真打）—— 云台+激光
- Arduino 烧录 `laser_gimbal.ino`，接 2 舵机 + 激光；PC 端 `python main.py --port COM3`。
- 可行性：**✅ 高**（硬件到手即可），需现场标定 KP 方向、死区、舵机角度范围。

### 阶段 4（移动+打击，可选进阶）
- GOOD DOG 负责靠近目标区域，云台负责精瞄激光，构成"走近→精瞄→打击"。
- 可行性：**⚠️ 中**（需两块板协同 + 摄像头随动标定）。

## 五、激光安全须知（务必遵守）

1. **只用低功率激光**（≤5mW，Class 3R 及以下），禁止使用可灼伤/致盲的大功率激光。
2. **禁止对人/动物/反光面**照射，工作区加挡板。
3. 加**硬件急停**（本方案 `S` 指令 + 常闭开关），异常立即断激光。
4. 主控上电默认**激光关闭**、云台回中（Arduino 固件已实现）。
5. 激光只对**植物病斑/虫害**，命中后短暂开启并冷却，避免连续灼烧植物。

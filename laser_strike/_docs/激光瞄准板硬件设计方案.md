## 0. 一句话概述

摄像头识别植物病害位置 → PC（WSL+RTX5060）计算瞄准角度 → 经串口下发 **Arduino 控制板** → 驱动 **2×MG90S 云台（水平+俯仰）** 把 **5mW 红激光** 打到病害/虫害点上；可选接 **GOOD DOG（STM32F407）底盘** 构成「行走→识别→发射→完成」闭环。

---

## 1. 系统原理（闭环链路）

```
摄像头 ──► AI识别(YOLOv8/色斑) ──► 瞄准计算(像素误差→角度) ──► Arduino控制板 ──► 云台(水平/俯仰)+激光
   ↑                                                                └── 串口 P/T/L/S 回传
   └────────────────────── 下一帧闭环 ◄─────────────────────────────────────┘
```

- **识别**：每帧跑 YOLOv8（或 HSV 色斑兜底），输出目标框 `(x1,y1,x2,y2,类别,置信度)`。
- **瞄准**：取目标中心 `(cx,cy)` 与图像中心误差，比例控制（P）映射到云台角度增量，含死区与限幅。
- **打击**：误差进入死区（已瞄准）→ 开激光；超差 → 关激光继续追。
- **安全**：健康叶片不打；两次射击有冷却；可硬件急停。

## 2. 硬件选型与 BOM（建议）

| 部件 | 建议型号 | 数量 | 说明 |
|------|---------|------|------|
| 摄像头 | USB 摄像头 或 已有 **OpenMV** | 1 | 320×240 JPEG 串口上传（OpenMV 模式） |
| 识别主机 | 本机 **WSL2 + RTX 5060**（CUDA 实测可用） | 1 | 跑 YOLOv8 训练/推理 |
| 主控 MCU | **Arduino Nano / Uno**（或 STM32F103） | 1 | 串口 ASCII，控舵机+激光 |
| 云台舵机 | **MG90S** 金属齿 | 2 | 水平+俯仰 各一，PWM（Servo 库） |
| 激光模块 | **5mW 红光激光二极管**（≤Class 3R） | 1 | MOS/三极管驱动，务必安全 |
| 激光驱动 | N-MOS（如 AO3400）/ 三极管 2N2222 | 1 | 开关激光，PWM/数字 |
| 电源 | 5V DC（舵机独立供电，≈1A） | 1 | 勿与 MCU 共用大电流路径 |
| 串口 | USB-TTL（CH340/CP2102） | 1 | PC↔Arduino 115200 |

> 注：GOOD DOG（STM32F407）的 4 个直流电机用于**移动**，不适合高频瞄准；瞄准用**舵机云台**，二者可组合（GOOD DOG 走近 → 云台精瞄）。

## 3. 控制板电路设计要点

### 3.1 主控（Arduino Nano）
- 供电：`5V` 由稳压/5V 口提供；`GND` 与舵机、激光、串口**共地**。
- 引脚分配（建议）：
  - `D9` → PWM 舵机1（水平）；`D10` → PWM 舵机2（俯仰）
  - `D7` → 激光驱动 MOSFET 栅极
  - `TX/RX (D0/D1)` → 串口接 PC（USB-TTL）
  - `D2` → 急停输入（可选，硬件急停）

### 3.2 舵机驱动
- MG90S 工作电流 ~0.2–0.5A，峰值可到 ~1A；**舵机电源线单独 5V**，不与 MCU 主线共走，避免舵机启动电压跌落使 MCU 复位。
- 舵机信号线（黄/橘）直连 D9/D10 PWM；**舵机电源负极与 MCU GND 必须共地**。

### 3.3 激光驱动（MOS）
- N-MOS 低边开关：栅极 `D7`（经 100Ω 串阻 + 10k 下拉防误开），源极接 GND，漏极经激光二极管串联限流电阻（~20–50Ω）接 5V。
- **上电默认激光关**；`S` 急停指令或硬件急停立即断激光。
- 加反并联吸收/续流（激光为 LED 类负载，可加小电容/电阻吸收尖峰）。

### 3.4 电源与去耦
- 输入 5V 口（DC 座/排针），**1000uF 电解** + 0.1uF 贴片去耦。
- MCU 电源端加 0.1uF；舵机电源端加 100uF 就近。

### 3.5 串口
- USB-TTL 与 Arduinio RX/TX 交叉（TX→RX, RX→TX），115200；共地。

## 4. 原理图架构 / 连接表（net-list 思路）

| 模块 | 连接 |
|------|------|
| Servo1 PAN | `D9` 信号，5V，GND |
| Servo2 TILT | `D10` 信号，5V，GND |
| Laser Driver | `D7`→MOS 栅极；激光管→限流电阻→5V；MOS 源→GND |
| Power 5V | DC/排针 → 主供电节点 |
| UART | `TX`→PC_RX，`RX`→PC_TX，GND |
| Emergency Stop | `D2`（可选）→ 急停按钮 |

**串口协议（ASCII，每行 `\n` 结尾）**
```
P<0-180>   水平舵机角度
T<0-180>   俯仰舵机角度
L1 / L0    激光 开/关
S          急停（回中 + 关激光）
```

## 5. 布线规则（2 层 PCB 建议）

1. **线宽/间距**：信号线 ≥0.2mm；电源线 ≥0.5mm（舵机 5V ≥0.5mm）；间距 ≥0.2mm，安全间距 ≥0.3mm。
2. **地平面**：底层大块铺铜作 GND；舵机大电流地、激光地、MCU 地**分开走再单点汇到电源地**（避免共地干扰）。
3. **电源走线**：舵机 5V 电源线走粗、短，就近去耦；避免与 PWM 信号线长距离平行。
4. **PWM/信号**：舵机 PWM 信号勿与激光开关/电源线平行走，减少串扰；可加终端/下拉。
5. **激光 MOS**：栅极走线短，加 10k 下拉防上电误开；激光线远离板边/天线。
6. **EMC/ESD**：串口、电源入口加 ESD/压敏；板边缘、接口处做防护。
7. **丝印**：标清方向（舵机接线、激光极性、电源正负、串口 TX/RX）。

## 6. 软件管线与接口（现状）

- 已实现：`config.py`（参数）/ `detector.py`（Yolo+Blob）/ `aiming.py`（PID 瞄准）/ `actuator.py`（Serial+Sim）/ `main.py`（闭环）/ `mission.py`（行走→识别→发射）。
- **试验结论（实测）**：`cv2`/`numpy`/`ultralytics` 可 import；但 WSL 加载 `/mnt` 盘的 `.pt` 模型报 `OSError [Errno 22]`（9P mmap 限制，需把模型放到 WSL 内 ext4 路径）；且 `ultralytics` 存在 `~/.local`（用户级）与 conda env 双 python 冲突；`pyserial` 未装。**这些属软件环境待修，不影响硬件板设计。**

---

## 7. 激光安全（务必遵守）

1. 只用低功率激光（≤5mW，Class 3R 及以下），禁止使用可致盲的大功率激光。
2. 禁止对人/动物/反光面照射，工作区加挡板。
3. 加**硬件急停**（`S` 指令 + 常闭开关），异常立即断激光。
4. 主控上电默认激光关、云台回中（Arduino 固件已实现）。
5. 激光只对植物病害/虫害，命中后短暂开启并冷却，避免连续灼烧植物。

## 9. 结论

本板是一个**低成本的 Arduino 舵机云台 + 激光驱动的激光瞄准控制板**，配合 WSL GPU 识别闭环，可完成「识别→瞄准→打击」。硬件选型贴近本机已有资产（OpenMV/STM32/GPU/YOLO），软件管线已搭好。**主要待打磨点是软件环境（模型加载/双python）与现场标定；硬件板本身设计合理、可打样。** 具体方案请师兄从供电、布线、激光安全、PCB 打样角度批评指正。

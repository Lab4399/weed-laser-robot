# OpenMV H7-50V8 T6 视觉节点

除草识别小车的视觉侧固件。运行环境：OpenMV IDE + MicroPython。

## 文件职责

| 文件 | 职责 |
|---|---|
| `config.py` | 全部可调参数。禁止在业务代码里散落魔法数字 |
| `detector.py` | 杂草识别。支持 FOMO（Edge Impulse）与颜色阈值两种后端 |
| `tracker.py` | 多目标筛选、航向误差计算、目标丢失计数 |
| `ranging.py` | 双目测距（Z = f·B/d）与单目接近度兜底 |
| `servo.py` | 云台舵机闭环（视觉内环） |
| `uart_protocol.py` | 协议 v1.1 帧组装 + CRC-8 |
| `main.py` | 主循环与调度 |

## 部署步骤

1. **确认引脚**。`config.py` 里的 `UART_ID` 和舵机编号必须按实际板子丝印改。
   OpenMV H7 系列不同批次的可用 UART 与外设映射不同，写错不会报错，只会静默不通信。

2. **交叉接线**（这一步接反是最常见的不通信原因）：
   ```
   OpenMV TX  →  STM32F407 RX (PA10 / USART1_RX)
   OpenMV RX  ←  STM32F407 TX (PA9  / USART1_TX)
   GND        ↔  GND            ← 必须共地，否则电平参考不同，通信随机出错
   ```
   ⚠️ OpenMV 与 F407 都是 3.3V 电平，**不要串接 5V 器件**，也不要引入电平转换芯片
   （多一级转换就多一个故障点，且会引入传播延迟）。

3. **上电顺序**：先给 F407 上电（它进入等待状态），再给 OpenMV 上电。
   反过来也可以，但要注意 F407 侧的链路超时逻辑必须能容忍"上电时视觉节点还没启动"。

4. **首轮验证**（不接电机，只接 USB 转串口）：
   ```python
   # 在 OpenMV IDE 的 REPL 中
   import uart_protocol
   uart_protocol.FrameBuilder.selftest()
   ```
   再把串口助手接到 OpenMV 的 TX 上，波特率 115200，应能看到：
   ```
   @T,0,NONE,0.00,0,0,0,0,0*XX
   @T,1,NONE,0.00,0,0,0,0,0*XX
   ...
   ```
   用 `*XX` 手动核对 CRC（CRC-8, poly=0x07, init=0x00，覆盖 `*` 之前的全部字节）。

## 关键设计说明

### 心跳必须每 50 ms 发一帧

`config.HEARTBEAT_MS = 50` 不是性能指标，是安全设计。原因：
"看不到杂草"和"串口线断了"在 F407 侧的现象都是"没有新帧"，但处理方式必须相反
（前者继续作业，后者立即停车）。只有让 OpenMV 在无目标时也持续发 `CLASS=NONE` 帧，
F407 才能用帧超时区分这两种情况。

### 推理慢 → 心跳机制

单帧推理可能耗时数百毫秒，远超 50 ms 的心跳周期。`main.py` 的处理方式：
推理结束后发新鲜结果，推理进行中按心跳周期重发上一次结果。

由此推导出 F407 侧的一个硬约束：

```
F407 的 LINK_TIMEOUT_MS  >  单帧推理最坏耗时 × 1.5
```

`main.py` 的调试打印会输出 `infer_ms_max`，这个值就是 F407 配置的取值依据。
取小了会导致每次推理都触发误超时，小车一顿一顿地走。

### 云台闭环为什么要冷却

舵机转动 → 视角变化 → 目标位移 → 误差"看起来"变大了。
但这个位移是舵机自己造成的。若每帧都据此更新舵机，就构成正反馈，表现为
画面持续左右扫动（自激振荡）。`servo.py` 用了三步抑制：死区 + 单步限幅 + 动作后冷却。

### 协议 v1.1 相对 v1.0 的两处改动

1. 尾部加 `*HH` CRC-8 校验。原帧无校验，一个被噪声翻转的字节就能把
   `CX=173` 变成 `773`，而这条链最终驱动电机。
2. 新增 `DIST` 字段。项目核心路线是双目测距，协议不预留则后续加字段要全链路重改。

## 待标定项

以下参数当前是占位值，**必须在实机上标定后才能用于联调**：

| 参数 | 位置 | 标定方法 |
|---|---|---|
| `GIMBAL_ANGLE_MIN/MAX` | `config.py` | 手动断电转动云台至机械极限，读出角度 |
| `GIMBAL_KP` | `config.py` | 从 0.01 递增，直到出现振荡后退回一半 |
| `BLOB_THRESHOLDS` | `config.py` | OpenMV IDE 阈值编辑器，在田间实际光照下取 |
| `STEREO_FOCAL_PX` / `STEREO_BASELINE_MM` | `config.py` | 相机标定（棋盘格）+ 测基线 |
| `MODEL_PATH` 与 `_labels` 顺序 | `detector.py` | 标签顺序必须与训练时一致，否则作物会被识别成杂草 |
